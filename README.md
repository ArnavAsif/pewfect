## 🚀 Getting Started

### Prerequisites

- [Shopify CLI](https://shopify.dev/docs/themes/tools/cli) `>=3.0`
- Node.js `>=18.x`
- A Shopify store account

<br/>

```bash
# 1. Clone the repo
git clone https://github.com/yourusername/pawfect.git
cd pawfect

# 2. Install Shopify CLI
npm install -g @shopify/cli @shopify/theme

# 3. Connect to your store
shopify auth login --store=your-store.myshopify.com

# 4. Run locally
shopify theme dev --store=your-store.myshopify.com

# 5. Push to live
shopify theme push
```
